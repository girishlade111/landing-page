## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/codeenhance-ai-landing.git
   cd codeenhance-ai-landing
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## 🔧 Customization

### Changing Colors
Edit the color palette in `tailwind.config.js`:

```javascript
colors: {
  primary: {
    // Your primary colors
  },
  accent: {
    // Your accent colors
  }
}
```

### Modifying Content
Update component files in `src/components/`:

- `HeroSection.tsx` - Main headline and CTAs
- `FeaturesSection.tsx` - Feature cards and descriptions
- `AboutSection.tsx` - About Girish Lade and Lade Stack
- `ShowcaseSection.tsx` - Demo and code examples
- `Footer.tsx` - Contact info and social links

### Adding Animations
Extend Framer Motion animations in `tailwind.config.js`:

```javascript
animation: {
  'your-animation': 'your-animation 1s ease-in-out',
}
```
